# 슈퍼 전투기 대작전 ✈️

초등학교 3학년 아이와 함께 즐기는 모바일 웹 전투기 슈팅 게임입니다.
설치 없이 브라우저만 있으면 바로 플레이할 수 있어요.

## 바로 플레이

👉 **https://dreamccm.github.io/air-fight/**

## 실행 방법

`index.html` 파일을 브라우저로 열면 끝입니다.

로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

휴대폰에서 하려면 PC와 같은 와이파이에 연결한 뒤
`http://<PC의 IP 주소>:8000` 으로 접속하세요.
(GitHub Pages에 올리면 어디서나 링크로 즐길 수 있습니다.)

## 조작법

| 동작 | 방법 |
|---|---|
| 이동 | 화면을 손가락으로 끌기 (PC는 마우스 드래그 / 방향키) |
| 발사 | 자동 발사 |
| 폭탄 | 오른쪽 아래 💥 버튼 (PC는 스페이스바) |
| 일시정지 | 오른쪽 위 ❚❚ 버튼 (PC는 ESC) |

## 게임 요소

- **아이템**
  - 초록 `＋` : 체력 1 회복
  - 파랑 `⚡` : 총알 강화 (최대 4단계)
  - 노랑 `🛡` : 6초간 보호막 (한 번 막아줌)
  - 분홍 `💣` : 폭탄 1개 추가 (최대 5개)
- **적 기체** : 정찰기(빨강) · 폭격기(주황, 3발 확산) · 지그재그기(보라)
- **보스** : 약 32초마다 등장, 부채꼴 탄막과 원형 탄막을 번갈아 사용
  - 처치하면 500점 + 아이템 + 폭탄 1개
- **레벨** : 800점마다 상승하며 적이 더 빠르고 많아짐
- **순위표** : 게임 오버 시 이름(최대 6자)을 남기면 TOP 10에 기록됩니다.
  시작 화면과 게임 오버 화면에 상위 5명이 표시되고, 방금 세운 기록은 강조돼요.
  기록은 그 기기의 브라우저에 저장됩니다 (localStorage). 서버가 없으므로
  다른 기기와는 순위표가 공유되지 않습니다.

## 아이와 함께 즐기는 팁

- 처음에는 체력 5칸, 폭탄 2개로 시작하니 부담 없이 도전할 수 있어요.
- 어렵다고 하면 `index.html` 안의 `maxHp: 5` 값을 늘리거나,
  `game.bossTimer > 32` 의 숫자를 키워 보스 등장을 늦출 수 있습니다.
- 더 어렵게 하려면 `spawnTimer` 계산식의 `1.0` 값을 줄여 보세요.

## 기술

의존성 없는 순수 HTML + Canvas + JavaScript 단일 파일.
터치 입력, 고해상도(DPR) 대응, Web Audio 효과음을 직접 구현했습니다.
